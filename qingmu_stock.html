⬆ 核心原则
只买第二阶段：均线明确向上 + 股价站稳均线上方，趋势已确立，风险收益比最优。
绝不买第四阶段：均线向下 + 股价在均线下方，所谓"低价"是陷阱，越买越套。
判断标准：30日均线5日变化率 > 2% 为向上，< -2% 为向下，中间为走平。
买入指标详解
6个量化指标 · 基于近120个交易日数据 · 前29日MA30为null
指标 01
30日均线方向
判断当前趋势是否处于第二阶段的核心条件
MA30今日 = 近30日收盘均值 MA30_5日前 = 5日前的MA30值 5日变化率 = (MA30今日 - MA30_5日前) ÷ MA30_5日前 × 100%
变化率 > +2%→ 向上 ✓
变化率 < -2%→ 向下 ✗
-2% ≤ 变化率 ≤ +2%→ 走平
✓ 买入条件
股价 > MA30 且 方向 = 向上
指标 02 ★必须满足
突破底部区域
近60日形成盘整区，今日有效突破 + 放量确认
底部区域（近60日同时满足）: 1. 最高-最低 < 最低×15% 2. 期间未向上突破 突破确认: 收盘价 > 底部最高价 × 1.03 成交量确认: 今日量 > 近5日均量 × 2
筛选器必须条件，不满足不显示股票
指标 03
上方空间
确保后续上涨空间充足，避免追高被套
近120日最高价（不含今日） = 近120交易日收盘价最大值 上方空间 = (近120日最高价 - 今日收盘价) ÷ 今日收盘价 × 100%
上方空间 > 20%→ 满足
上方空间 ≤ 20%→ 不满足
指标 04
相对强度
个股表现强于大盘，说明资金在积极流入
个股20日涨幅 = (今日收盘 - 20日前收盘) ÷ 20日前收盘 × 100% 大盘20日涨幅 = 同期模拟大盘涨幅 相对强度 = 个股20日涨幅 - 大盘20日涨幅
相对强度 > 0→ 强于大盘 ✓
相对强度 ≤ 0→ 弱于大盘
指标 05
回调缩量
突破后健康回调，说明筹码稳定，洗盘充分
时间窗口：突破后5个交易日内 回调定义: 收盘价 < 前一日收盘价 缩量标准: 回调日成交量 < 突破日成交量×0.6
缩量回调存在→ 满足
无回调或放量回调→ 不满足
指标 06 ★加分项
底部形态完成
识别到头肩底、双底或底部三角形，加1分
头肩底右肩量<头部量，突破量>右肩×2
双底两底价差<3%，第二底量<第一底量
底部三角形三次探底，高点下移，量能萎缩
加分项：有形态则匹配分数+1，无形态但指标2满足也可买入
卖出指标详解
4个卖出信号 · 以第120日为当前状态展示 · 静态信号不跟踪持仓
卖出 01
初始止损点
买入时立即设定，控制单笔亏损上限
盘整区最低价 = 指标2底部区域最低价 初始止损价 = 盘整区最低价 × 0.97 执行: 股价跌破止损价 → 立即卖出
止损幅度约为底部区域下方3%
⚡ 立即执行
卖出 02 · 简化版
移动止损点
随价格上涨上移止损，保护既有利润
完整版: 每次回调后，止损上移至 回调最低点（逐步上移） 简化版（本系统采用）: 股价跌破MA30当日值 → 卖出 取值逻辑: 以MA30为动态止损线
触发条件收盘价 < MA30
⚡ 简化版 · 参考书P50-51
卖出 03
均线走平预警
趋势由升转平的早期信号，提示减仓
当前5日斜率 = (MA30今日 - MA30_5日前) ÷ MA30_5日前 × 100% 5日前斜率 = 历史记录的斜率值 "由升转平" 信号触发条件: 5日前斜率 > 2% 且 当前5日斜率 ∈ [-2%, 2%]
触发预警→ 减仓一半
卖出 04
对称性目标位
预估上涨目标，到达后锁定部分利润
突破点 = 突破底部区域时的收盘价 底部高度 = 底部最高价 - 底部最低价 目标价 = 突破点 + 底部高度 注意: 只在突破时计算一次， 不随后续价格更新
到达目标价→ 卖出一半仓位
📈 利润锁定
底部形态图解
三大底部形态 · 均在近120个交易日内识别 · 均为买入加分项
形态一 头肩底 最可靠的底部反转形态
▼
形成过程
1. 第一次下跌反弹 → 形成左肩低点
2. 再次下跌，跌得更深 → 形成头部最低点
3. 再次下跌，但未能创新低，反弹 → 形成右肩低点
4. 突破两个反弹高点连成的颈线 → 买入
量化识别条件
  • 三个低点：左肩、头（最低）、右肩
  • 左肩与右肩价格相差 < 3%
  • 两个反弹高点基本水平（颈线）
  • 右肩成交量 < 头部成交量
  • 突破颈线时成交量 > 右肩量 × 2
失败信号：突破颈线后跌回颈线以下
形态二 双底（W底） 最常见的底部反转形态
▼
形成过程
1. 股价下跌触底 → 形成第一底，成交量相对较大
2. 反弹至颈线区域
3. 再次回落，但未跌破第一底 → 形成第二底，量能缩小
4. 放量突破颈线 → 买入
量化识别条件
  • 两个低点价格相差 < 3%
  • 第二底成交量 < 第一底成交量
  • 突破颈线时成交量 > 近5日均量 × 2
失败信号：第二底跌破第一底价格
形态三 底部三角形 蓄势待发的收敛形态
▼
形成过程
1. 三次探底，低点价格接近（差 < 3%）
2. 每次反弹高点逐渐下移，形成下降压力线
3. 成交量逐步萎缩，市场分歧收窄
4. 向上放量突破压力线 → 买入
量化识别条件
  • 三次探底，低点价格相差 < 3%
  • 反弹高点逐渐下移
  • 成交量逐步萎缩
  • 向上突破时成交量 > 近5日均量 × 2
失败信号：向下跌破三角形下轨
选股六招
青木选股体系 · 从成交量到形态的完整检查清单
第1招洞悉成交量变化
▼
检查项1
底部区域成交量是否持续萎缩？（市场失去兴趣 = 好事）
检查项2
突破时成交量是否 > 近5日均量 × 2？（放量确认）
检查项3
突破后回调时量能是否 < 突破日 × 0.6？（缩量健康）
检查项4
右肩（或第二底）成交量是否小于左肩（或第一底）？
第2招判断均线方向
▼
检查项1
30日均线5日变化率是否 > 2%？（方向明确向上）
检查项2
股价是否站稳在MA30上方？
检查项3
MA30是否由走平转为向上？（由一阶段进入二阶段的信号）
第3招确认突破有效性
▼
检查项1
收盘价是否 > 底部最高价 × 1.03？（突破上沿3%）
检查项2
突破日是否以阳线收盘？
检查项3
次日是否维持突破，而非跌回区间内？（假突破排除）
第4招评估上方空间
▼
检查项1
距离120日最高收盘价的空间是否 > 20%？
检查项2
上方是否有明显密集套牢区？（阻力位）
检查项3
对称性目标价（突破点 + 底部高度）是否在空间范围内？
第5招比较相对强度
▼
检查项1
个股20日涨幅是否 > 大盘同期涨幅？（相对强度 > 0）
检查项2
大盘走弱时，个股是否依然坚挺？（资金青睐）
检查项3
同板块中，该股是否排在涨幅前列？（板块强股）
第6招识别底部形态
▼
检查项1
是否识别出头肩底、双底或底部三角形其中之一？
检查项2
形态的量价配合是否符合标准？（右低量、突破放量）
检查项3
形态完成时间是否在近120日内？
结论
有形态则置信度更高，无形态但指标2满足也可买入（加分项）
